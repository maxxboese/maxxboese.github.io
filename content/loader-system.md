### Project Overview
Developed a multi-game loader system with a focus on modular architecture and automated software delivery.

*   **Core Features:** Automated update fetching from GitHub, custom licensing logic, and hardware ID (HWID) management.
*   **Security:** Implemented code signing using `signtool.exe` to ensure software integrity and security.
*   **Tech Stack:** Python, C#, and C++ for low-level system interaction and UI development.
